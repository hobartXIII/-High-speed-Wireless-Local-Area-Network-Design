1. 標準依據

  • 本章內容依據 IEEE Std 802.11 的 MAC 架構與服務定義。
  • 相關修訂：802.11e（QoS）、802.11i（安全）、802.11f（IAPP，AP 間漫遊）。
  • 相關的其他 802 標準：802.2 LLC（上層介面）、802.1X（port-based 認證）、802.10（實際執行 challenge/response 計算）、IEEE 802 48-bit 位址空間。

2. 無線 LAN 與有線 LAN 的主要差異（Major differences between Wireless LAN and Wired LAN）

位址 ≠ 位置（Destination address does not equal destination location）

  • 有線 LAN：位址等同實體位置（In wired LANs, an address is equivalent to a physical address）。
  • 802.11：可定址的單位是站台（STA）；STA 是訊息的目的地，但不是固定位置（not a fixed location）。

媒介影響設計（The media impacts the design）

802.11 PHY 與有線媒介本質不同：點對點連線距離有限（limited physical point to point connection ranges）、使用共享媒介（Use a shared medium）、不受外部訊號保護（unprotected from outside signals）、可靠度比有線 PHY 低很多（significantly less reliable than wired PHYs）、拓樸是動態變化的（dynamic topologies）。

移動站台的處理（Impact of handling mobile stations）

  • Portable station：會換地點，但只在固定位置時使用。
  • Mobile station：移動中也在存取 LAN。
  • 電波傳播效應讓兩者的界線變模糊（Propagation effects blur the distinction between portable and mobile stations）。

與其他 802 層的互動（Interaction with other 802 layers）

  • 802.11 對上層（LLC）必須看起來就像一般的 802 LAN（appear to higher layers (LLC) as a current 802 style LAN）。
  • 站台的移動性必須在 MAC 層內處理（Station mobility has to be handled within the MAC layer）（802.11f）。

3. 802.11 WLAN 特性（802.11 Wireless LAN Characteristics）

  • 速率：1、2、5.5、11、22、33、6、9、12、18、24、36、48、54、72、150、500、1000 Mbps；802.11ax（Wi-Fi 6；Wi-Fi 6E 使用 5.925–7.125GHz）600–9608 Mbps；802.11be（Wi-Fi 7）40000 Mbps（講義數據）。
  • 傳輸媒介：無線電（Transmission medium: Radio）。
  • CSMA/CA 協定：
    • 用不同的 contention window 提供優先權（802.11e）（Provides priority scheme using different contention windows），進而提供有延遲保證的傳輸服務（delay guaranteed transmission service）。
    • 避免大部分碰撞，因此傳輸延遲可以保證（avoids most of the collisions so that the transmission delay can be guaranteed）。
    • 頻寬公平性是否成立需要長時間觀察（Bandwidth fairness is guaranteed or not (to observe long time)）；各站台實際用到的頻寬可能不同 → 講義提問：未來是否需要負載分擔機制（load sharing scheme）？

5. 802.11 架構元件（802.11 Architecture Components）

ESS、DS 與 Portal：資料怎麼走 動畫
依講義第 11、16、19 頁重繪。虛線為無線媒介（WM），實線為 DS 媒介（DSM）。Distribution：STA1 → STA4；Integration：STA1 → 有線 LAN（輸出點是 Portal）。
元件定義重點
WM（Wireless Medium）實作無線 LAN 的媒介（The medium used to implement a wireless LAN）—
STA（Station）具備符合 802.11 的 MAC 與 PHY 介面的任何裝置（Any device that contains an 802.11 conformable MAC and PHY interface to the wireless medium）AP 也是一種 STA
SS（Station Services）在 BSS 內的站台間傳送 MSDU 的服務集合（The set of services that support transport of MSDUs between Stations within a BSS）每個 STA 都有
BSS（Basic Service Set）由單一 Coordination Function 控制的一組 STA（A set of STAs controlled by a single CF）802.11 LAN 的基本單位（the basic building block of an 802.11 LAN）；離開覆蓋範圍就無法直接與成員通訊
IBSS（Independent BSS）Ad-Hoc 網路站台夠近就能直接連線，不需事先規劃（close enough to form a direct connection, without pre-planning）
DS（Distribution System）連接多個 BSS 以形成 ESS 的系統（A system used to interconnect a set of BSSs to create an ESS）用於 Infrastructure 網路
DSM（DS Medium）DS 所使用的媒介（The medium used by a DS）802.11 在邏輯上把 WM 與 DSM 分開（logically separates the WM from the DSM），兩者用途不同
DSS（DS Services）DS 提供的服務，讓 MAC 能在 ESS 內跨 BSS 傳送 MSDU（enables the MAC to transport MSDUs between BSSs within an ESS）經由 AP 存取
AP（Access Point）具 STA 功能並提供 DS 存取的實體（Any entity that has STA functionality and provides access to the DS）AP = SS ＋ DSS
ESS（Extended Service Set）互連的多個 BSS，看起來像單一 BSS（A set of interconnected BSSs which appears as a single BSS）對 LLC 而言與 IBSS 無異；站台在 ESS 內移動對 LLC 透明（transparently to LLC）
BSA / ESABSS / ESS 成員可以通訊的區域ESA ≥ BSA
Portal與傳統有線 LAN 整合的邏輯元件（a logical architecture component to integrate with a traditional wired LAN）所有來自非 802.11 LAN 的資料都經 Portal 進入（All data from non-802.11 LANs enters the 802.11 architecture via a portal）
  • STA 與 AP 的關聯是動態的（STA to AP Association is Dynamic）：站台會開機、關機、進出範圍；要成為 Infrastructure BSS 的成員必須先 Associated。
  • DS 與多個 BSS 讓 802.11 能建立任意大小與複雜度（arbitrary size and complexity）的無線網路。

6. BSS 的空間關係

部分重疊・實體分離・同地點共存 圖解
  • BSS 可以部分重疊（partially overlap）（常用來達成連續覆蓋）、實體分離（physically disjoint）、或同地點共存（physically collocated）。
  • 同一空間內可以同時存在多個 IBSS 或 ESS，例如：在 ESS 網路範圍內運作的 ad-hoc 網路，或不同組織各自架設、實體相鄰的 802.11 網路。

7. Portal 與 Bridge

  • Bridge 原本用來延伸同類 MAC 的距離（range extension between like-type MAC layers）；802.11 已由 ESS（DS + AP）提供任意覆蓋範圍，所以不需要靠 bridge 延伸 PHY 距離。
  • Bridge 也用來連接不同類型的 MAC（interconnect MAC layers of different types）。橋接到 802.11 時會遇到問題：要橋接到 DSM 還是 WM？
  • Portal 必須處理 BSS 成員的動態變化（dynamic membership of BSSs），以及移動性帶來的位址與位置對應（mapping of address and location）。
  • 實體上，Portal 可能包含、也可能不包含橋接功能，取決於 DS 的實作。

8. 邏輯服務介面（Logical Service Interface）

  • DS 不一定等同現有的有線 LAN，可以用多種技術建構（包括現有的 802.x 有線 LAN）。
  • 802.11 不限制 DS 是 Data Link 層或 Network 層、集中式或分散式。
  • 802.11 只定義服務，不定義 DS 的實作（specifies services instead of specific DS implementations），服務分成 SS 與 DSS 兩類。

  • 講義的分類：原本 9 項服務中，6 項支援 MSDU 傳送（Six to support MSDU delivery between stations）、3 項控制存取與機密性（three to control 802.11 access and confidentiality）（Authentication、Deauthentication、Privacy）。每項服務由一種或多種 MAC frame 支援。
  • SS 存在於每個 802.11 站台（含 AP），由 MAC 實體使用。
  • DSS 用來跨越媒介與位址空間的邏輯邊界（Used to cross media and address space logical boundaries），由 DS 提供，透過同時提供 DSS 的 STA（也就是 AP）存取。

MAC 的三種訊息（three types of messages）

  • Data：走 MAC 資料服務路徑；Management：走 MAC 管理服務路徑；Control。
  • 補充常見的 frame：Management 有 Beacon、Probe Request/Response、Authentication、Deauthentication、Association / Reassociation Request/Response、Disassociation；Control 有 RTS、CTS、ACK、PS-Poll。

9. 多重邏輯位址空間（Multiple Logical Address Spaces）

  • WM、DSM 與整合的有線 LAN 可能是不同的實體媒介，也可能在不同的位址空間運作。
  • 802.11 只使用並規範 WM 的位址空間（only uses and specifies the use of WM address space），每個 802.11 PHY 只在單一媒介（WM）運作。
  • 802.11 採用 IEEE 802 的 48-bit 位址空間。
  • 例：DS 使用網路層定址時，WM 位址空間與 DS 位址空間就不同。

補充802.11 資料訊框最多有 4 個位址欄位，用 To DS / From DS 兩個 bit 表示方向：

10. DS 內的訊息分送（Distribution of Message Within a DS）

Distribution

  • 在 DS 內傳送 MSDU 的服務，依據 Association 資訊找出目的地。
  • 例：STA1 傳給 STA4 → STA1 送給所屬 AP（input）→ 經 DS → 到 STA4 所屬的 AP（output）→ 送達 STA4。在第 5 節的動畫選「Distribution」可以看到這條路徑。
  • DS 內部怎麼傳，不在 802.11 規範內（How the message is delivered within the DS is not specified by 802.11）。
  • DS 要判斷輸出點需要的資訊，來自三項 association 相關服務：Association、Reassociation、Disassociation。

Integration

  • 讓 DS 與既有網路之間能傳送 MSDU（enables delivery of MSDUs between the DS and an existing network）。
  • 若目的地是整合的 LAN 成員，輸出點就是 Portal 而不是 AP。
  • 送往 Portal 的訊息會觸發 Integration 服務，負責把訊息從 DSM 送到整合 LAN 的媒介，包括必要的媒介或位址轉換（media or address translation）。

13. 存取與機密性控制（Access and Confidentiality Control Services）

  • 有線 LAN 設計假設媒介是封閉、不共享的（assumes the closed, non-shared nature of wired media）；802.11 開放共享的特性違反了這個假設。
  • 因此需要兩項服務，才能達到有線 LAN 原本就有的功能：
    • Authentication：取代有線的「實體接線」→ 後來由 802.1X port-based 認證強化。
    • Privacy：提供封閉有線媒介的機密性 → 後來由 802.11i 強化。
  • 有線 LAN 中，能接上實體線路就代表有權使用 LAN（access to a physical connection conveys authority to connect to the LAN）；無線 LAN 不能這樣假設。
  • 若兩個站台之間沒有建立雙方都能接受的認證等級，就不能建立 association（an association shall not be established）。

14. Authentication 服務

  • 支援從不安全的方式（unsecured schemes）到公開金鑰密碼認證（public key cryptographic authentication）等各種等級；講義列出 Open System 與 Shared Key 兩種。
  • 是 link level 認證（802.11 站台之間），不是 end-to-end 或 user-to-user；需要更高層的認證由上層處理。
  • Challenge/Response 三步驟：Assertion（宣告身分，Assertion of identity）→ Challenge（挑戰該宣告，Challenge of Assertion）→ Response（回應挑戰，Response to Challenge）。
Challenge / Response 的三個例子 動畫

補充Shared Key 認證使用 WEP 金鑰加密 AP 給的 challenge text；因為攻擊者可以同時截到明文與密文，反而會洩漏金鑰資訊，實務上已不建議使用。

其他規定

  • 802.11 使用 802.10 的服務執行實際的 challenge / response 計算。
  • 提供 MIB 功能，讓外界查詢 STA 支援哪些認證演算法。
  • 要求雙向、雙方都接受且成功的認證（mutually acceptable, successful, bi-directional authentication）。
  • 一個 STA 可以同時與多個 STA（和 AP）完成認證。
  • Authentication 可能很耗時，可以獨立於 Association（invoked independently of the Association service） 執行。
  • Pre-authentication：STA 還連著原本的 AP 時，先與其他 AP 完成認證；標準不強制，但因為 association 之前必須先認證，預先認證可以加速 reassociation（speedup the reassociation process）。
  • 順序：先 Authentication，才能 Association。

16. 考前自我檢查

  • 說明「位址 ≠ 位置」的意義
    有線 LAN 的位址等於實體位置；802.11 的可定址單位是 STA，它是訊息的目的地，但會移動，不是固定位置。
  • 說明 802.11 對 LLC 要呈現什麼樣子，以及移動性在哪一層處理
    對 LLC 要看起來像一般的 802 LAN；移動性在 MAC 層內處理（802.11f）。
  • 定義 BSS、IBSS、ESS、DS、DSM、DSS、AP、Portal、BSA、ESA
    見第 5 節表格。關鍵：BSS 由單一 CF 控制；ESS 對 LLC 看起來像單一 BSS；AP = SS + DSS；Portal 是接有線 LAN 的邏輯出入口。
  • 背出 DSSS / FHSS / OFDM 的最多重疊 BSS 數
    DSSS 2.4GHz：3；FHSS 2.4GHz：26；OFDM 5GHz：12。
  • 把十項服務分成 SS 與 DSS
    SS：Authentication、Deauthentication、Privacy、MSDU delivery。DSS：Association、Reassociation、Disassociation、Distribution、Integration。第 10 項：QoS。
  • 比較 Association / Reassociation / Disassociation 的發起者與特性
    Association、Reassociation 只能 STA 發起；Disassociation 任一方皆可，且是通知不能拒絕。
  • 分辨 Distribution 與 Integration
    Distribution：在 DS 內把 MSDU 送到目的 STA 所屬的 AP。Integration：目的地在有線 LAN，輸出點是 Portal，需做媒介或位址轉換。
  • 說出三種移動性類型與需要的服務
    No-transition：Association 即可。BSS-transition：還需要 Reassociation。ESS-transition：802.11 無法維持上層連線。
  • 說明無線 LAN 為何需要 Authentication 與 Privacy
    有線 LAN 假設媒介封閉、接上線就有權使用；無線是開放共享媒介，所以要用 Authentication 取代實體接線、用 Privacy 提供機密性。
  • 寫出 challenge / response 三步驟與三個例子
    Assertion → Challenge → Response。Open system（Null/Null）、密碼式、密碼學式（公鑰加密 X，私鑰解出）。
  • 說明 pre-authentication 的用途
    還連著舊 AP 時先和新 AP 認證；因為 association 前必須先認證，預先做好可以加速 reassociation。
