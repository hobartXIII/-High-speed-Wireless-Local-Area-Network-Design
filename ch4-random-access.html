🎲 隨機存取分析

來源：Random Access Analysis | iLearning 3.pdf（p.1–42）動畫與互動 6 個・圖解 5 張
PDF 共 42 頁，沒有封面頁，p.1 直接是多重存取協定的分類圖。p.9–10、p.35 是中文講義，其餘是英文。本章把 CH 1 的 CSMA/CD、CH 2-4 的 CSMA/CA 放回「隨機存取」這條演進線上，並用 Poisson 模型算出各協定的最大吞吐量。

隨機存取 = 有資料就送、撞了就隨機等一段時間再送。用 Poisson 流量模型可以算出吞吐量 S 與提供負載 G 的關係 S = G·P0：Pure ALOHA 的易受干擾期是 2 個訊框時間，S = Ge−2G，最大 18.4%（G = 0.5）；Slotted ALOHA 把它減半，S = Ge−G，最大 36.8%（G = 1）。CSMA 先聽再送、CSMA/CD 撞了立刻停、CSMA/CA 用隨機等待避開碰撞，一步步把吞吐量往上推。

  • 分類：Random access（ALOHA、CSMA、CSMA/CD、CSMA/CA）、Controlled access（Reservation、Polling、Token passing）、Channelization（FDMA、TDMA、CDMA）。
  • 吞吐量 S：每個封包傳輸時間內成功送出的封包數，0 < S < 1。G：每個封包時間內嘗試的次數（新 + 重送），G ≥ S。
  • Poisson：Pr[k] = Gke−G ⁄ k!；沒有其他封包的機率 P0 = e−(期間長度 × G)。
  • CSMA 三種 persistence：1-persistent（一直聽，閒了立刻送）、Nonpersistent（忙就隨機等再聽）、p-persistent（閒了以機率 p 送）。
  • 流量模型：CBR（傳統語音）、On-Off（封包語音）、Poisson（傳統資料）、IPP（突發資料）、MMPP（多媒體）。

3. ALOHA 協定（p.2–6）（ALOHA Protocol）

  • 起源（p.2）：1970 年代由 University of Hawaii 開發。
  • 基本想法：使用者有資料就送（transmit whenever they have data to be sent）。
  • 兩個以上使用者同時送出封包時發生碰撞，封包毀損。
  • 碰撞後（p.3）：傳送端等一段隨機時間再重送。等待時間一定要隨機，否則相同的封包會再撞一次。
  • 碰撞機制（p.4）：Node 1 的封包單獨送出，成功；Node 2、Node 3 的封包時間重疊而碰撞，兩者各自等待隨機時間後重送（3 先、2 後），就不再撞。
  • 封包長度一致（p.5）：圖中 A–E 五個使用者的封包長度都相同，因為封包大小一致時 ALOHA 的吞吐量最大。
ALOHA 的傳送流程（講義 p.6） 圖解

依講義第 4、5 頁的概念重繪。封包依 Poisson 過程到達（平均每個訊框時間 G 個，含重送），每個封包隨機屬於 6 個使用者之一；綠色成功、紅色碰撞。Slotted 模式下封包延到下一個 slot 開頭才送。按「跑 20000 個訊框時間」用大量樣本驗證 S 會接近公式。

4. 吞吐量的定義與假設（p.7–8、p.12）（Throughput）

  • Throughput（p.7）：每個封包傳輸時間內，成功通過通道送出的封包數。問題：ALOHA 通道的吞吐量是多少？
  • 假設（p.8）
    • 使用者數量無限多（Infinite population of users）。
    • 新訊框依 Poisson 分佈產生，平均每個封包時間 S 個（相當於 λ）。
    • 一個封包時間內產生 k 個封包的機率：Pr[k] = Ske−S ⁄ k!（一般寫法 P(X = k) = e−λλk ⁄ k!）。
  • 對 S 的觀察（p.12）
    • S > 1：產生封包的速度比通道能處理的還快。
    • 所以預期 0 < S < 1。
    • 如果通道處理得了所有封包，那麼 S 就是吞吐量（新封包進來多少，就成功送出多少）。

5. Poisson 分佈與 Poisson 過程（p.9–11）（Poisson Process）

  • Poisson 分佈的現象（p.9）：每小時到服務台的人數、每天家中電話的通數、每頁的錯字數、某路段的車禍數……共同特徵：在某時間區段內，平均會發生若干次「事件」，但有時多、有時少，所以發生的次數是隨機變數，對應的機率函數叫 Poisson 分佈。
  • Poisson 過程的三個特性：
    1. 在一個很短的時間區間 Δt 內，發生一次事件的機率與 Δt 成正比：λΔt。
    2. 在很短的時間內發生兩次以上的機率可以忽略。
    3. 在不重疊的時間段裡，事件各自發生的次數是獨立的。
  • 推導（p.10）：P(k, T) 表示長度 T 的時間區間內發生 k 次事件的機率（T 是區間長度，不是絕對時間）。
    1. 由 (1)(2)：P(1, Δt) = λΔt，P(k, Δt) = 0（k ≥ 2）。
    2. 把 T 切成 N 個短區間（T = NΔt），由 (3) 各區間獨立，所以是二項分佈：P(k, T) ≈ CNk(λΔt)k(1 − λΔt)N−k。
    3. 代入 Δt = T ⁄ N 整理：= [(λT)k ⁄ k!] × [N(N−1)…(N−k+1) ⁄ Nk] × [(1 − λT⁄N)N ⁄ (1 − λT⁄N)k]。
    4. 固定 k，令 N → ∞：中間那項 → 1（N − k ≈ N）、分母 (1 − λT⁄N)k → 1、分子用 (1 + α⁄N)N → eα（α = −λT）。
    5. 得到 P(k, T) = (λT)ke−λT ⁄ k!。
  • 圖形（p.11）：λ = 1、4、10 的 P(X = k)。λ 越大，峰值越往右移、越矮越寬；峰值大約在 k ≈ λ。
Poisson 分佈與二項分佈的逼近 互動
依講義第 10、11 頁重繪。實心長條是 Poisson P(k)；空心框是把 T 切成 N 段的二項分佈 CNkpk(1−p)N−k，p = λT ⁄ N。把 N 調大，空心框就貼合實心長條，這就是 p.10 推導的 N → ∞。

6. 提供負載 G 與 S = G·P0（p.13–14）（Packet Retransmission、Relation between G and S）

  • 重送（p.13）：站台除了產生新封包，也會重送之前碰撞的封包。
  • 假設新 + 重送的封包合起來也是 Poisson，平均每個封包時間 G 個：Pr[k] = Gke−G ⁄ k!。
  • G 叫做 offered load（提供負載）。
  • G 與 S 的關係（p.14）
    • 顯然 G ≥ S（嘗試數一定不少於成功數）。
    • 低負載、碰撞少：G ≈ S。
    • 高負載、碰撞多：G > S。
    • 任何負載下：S = G·P0，P0 是一個封包沒有遭遇碰撞的機率。
讀法：每個封包時間有 G 次嘗試，每次嘗試成功的機率是 P0，所以平均成功數 S = G × P0。接下來只要算出 P0。

7. 易受干擾期與 Pure ALOHA 吞吐量（p.15–17）（Vulnerable Period）

  • 問題（p.15）：灰色的封包在什麼條件下能完好送達？設封包長度 t，灰色封包在 t0 + t 開始送、t0 + 2t 送完。
    • 在 t0 到 t0 + t 之間開始的封包，會撞到灰色封包的開頭。
    • 在 t0 + t 到 t0 + 2t 之間開始的封包，會撞到灰色封包的結尾。
    • 所以 Vulnerable period 長 2t（從 t0 到 t0 + 2t）。
  • 吞吐量（p.16）：2 個封包時間內平均有 2G 個封包，沒有其他封包的機率 P0 = e−2G；代入 S = GP0 得 S = Ge−2G。
  • dS ⁄ dG = (1 − 2G)e−2G，令它 = 0 得 G = 0.5。
  • 最大吞吐量（p.17）：G = 0.5 時 S = 1 ⁄ (2e) = 0.184，最大通道使用率 18.4%。
Vulnerable period：另一個封包什麼時候開始會撞？ 互動
依講義第 15 頁重繪，時間以封包長度 t 為單位，灰色封包從 t0 + t 送到 t0 + 2t。Pure ALOHA 下只要另一個封包在長 2t 的區間內開始就會撞；Slotted ALOHA 只能在 slot 開頭送，只有同一個 slot 才會撞，易受干擾期減半成 t。

8. Slotted ALOHA（p.17–18）

  • 做法（p.18）：把時間切成離散的區間（slot），每個區間對應一個封包；封包只能在 slot 開頭送。
  • 易受干擾期減半：只剩 1 個封包時間。
  • 沒有其他封包的機率 P0 = e−G，所以 S = Ge−G。
  • 補充dS ⁄ dG = (1 − G)e−G = 0 → G = 1，最大 S = 1 ⁄ e ≈ 0.368，是 Pure ALOHA 的兩倍（講義 p.17 的圖上 Slotted 峰值也在 G = 1.0、約 0.37）。
  • 補充代價：所有站台要有共同的時間基準（時間同步）。

9. CSMA 與三種 persistence（p.19–24）（Carrier Sense Multiple Access）

  • Carrier Sense（p.19）：很多情況下，站台在用通道之前能分辨通道是不是正在使用。
  • 如果感測到通道忙碌，就沒有站台會嘗試使用，直到通道變閒。這就是 CSMA 協定的基本想法。
  • 三種變形（p.20）：1-persistent CSMA、Nonpersistent CSMA、p-persistent CSMA。
Persistence（p.21–23）通道忙碌時通道閒置時特性
1-persistent持續感測，等到閒置立刻送（機率 1）延遲小；但多個站台同時在等，閒下來的瞬間一起送 → 碰撞
Nonpersistent不持續聽，隨機等一段時間再感測立刻送碰撞少，但通道閒了可能沒人在聽，浪費時間、延遲大
p-persistent持續感測，等到閒置以機率 p 送；以 1 − p 等下一個 slot 再判斷介於兩者之間；用於 slotted 通道。等待後通道又忙，就當作碰撞進入退避
  • 1-persistent CSMA 的流程（p.23）：送之前先聽；通道忙就等到閒；通道閒就送；發生碰撞就等隨機時間，從頭再來。
  • 叫 1-persistent 是因為站台發現通道閒置時，以機率 1 傳送。
三種 persistence 的行為 動畫
依講義第 21 頁（Figure 12.10）重繪。通道在 0–4 忙碌，A、B 在忙碌期間各有一個訊框要送。1-persistent 兩人一直聽，通道一閒就同時送而碰撞；Nonpersistent 各自隨機等待，不撞但通道空了一段；p-persistent（p = 0.5）在每個 slot 擲硬幣。補充擲硬幣與等待時間是示意用的固定值。

各協定的 S–G 曲線 互動

  • 比較（p.24）：最低的是 Aloha，其次 Slotted Aloha，再來是 1-persistent、0.5-persistent、0.1-persistent CSMA；Nonpersistent 與 0.01-persistent CSMA 最高，接近 1。
  • p 越小，高負載時越不容易撞，吞吐量越高；代價是站台常常在等，延遲變大。
  • Nonpersistent 的曲線在 G 很大時仍然很高，因為忙碌時大家各自隨機散開，閒下來時同時送的機會小。

10. CSMA/CD（p.25–28）（CSMA with Collision Detection）

  • 兩個站台同時傳送時，雙方幾乎立刻就能偵測到碰撞（p.25）。
  • 與其把封包送完，不如在偵測到碰撞時立刻停止傳送。
  • 這個協定叫 CSMA with Collision Detection（CSMA/CD），用在 Ethernet。細節（2a、BEBA、jam、訊框格式）見 CH 1。
  • 三種狀態（p.27）：CSMA/CD 處在 contention（競爭）、transmission（傳送）、idle（閒置）其中之一。
  • 能量位準（p.28）：傳送訊框時能量位準是一般值；閒置時為 0；碰撞時兩個訊號疊加，能量明顯變高，站台就是靠這個偵測碰撞。

11. CSMA/CA（p.29–30）（CSMA with Collision Avoidance）

  • 用在 WiFi（p.29）。無線站台邊送邊收不容易偵測碰撞，所以改成避免碰撞。
  • 時序：持續感測通道（Busy）→ 發現閒置（Found idle）→ 等 IFS → Contention window（大小以 binary exponential 成長）→ Send frame → Time-out（等 ACK）。
  • 細節（SIFS／DIFS、退避凍結、RTS/CTS、NAV）見 CH 2-4。

12. 流量模型（p.34–42）（Traffic Model）

模型（p.34）例子怎麼產生封包
Constant-Bit-Rate（CBR）傳統（電路交換）語音以固定位元率 R 產生，封包間隔固定（p.36）
On-Off Source封包化語音ON 時以固定位元率 R 送、OFF 時不送；ON、OFF 的長度都是指數分佈（p.37–39）
Poisson Process傳統資料流量速率 λ，到達間隔是平均 1 ⁄ λ 的指數分佈（p.40）
Interrupted Poisson Process（IPP）突發（bursty）資料ON 時是速率 λ 的 Poisson、OFF 時不送（p.41）
Markov Modulated Poisson Process（MMPP）多媒體流量多個狀態，狀態 i 是速率 λi 的 Poisson；狀態間依機率 pij 轉移（p.42）

指數分佈（p.35）（Exponential Distribution）

  • 令 W 表示 Poisson 過程中，從開始到第一次事件發生的時間（隨機變數）。W 也代表兩次事件的間隔。
  • 由 Poisson：P(W > t) = P(在 [0, t] 中無事件發生) = e−λt，t > 0（就是 P(0, t)）。
  • 累積分佈：FW(t) = P(W ≤ t) = 1 − P(W > t) = 1 − e−λt。
  • 微分得機率密度：fW(t) = F′W(t) = λe−λt，t > 0。
  • 這叫指數分配。E(W) = 1 ⁄ λ（第一次事件發生的平均時間），Var(W) = 1 ⁄ λ2。

On-Off Source（p.37–39）

  • ON 狀態：以固定位元率 R 送；停留時間是平均 1 ⁄ β 的指數分佈，以速率 β 轉到 OFF。
  • OFF 狀態：不送；停留時間是平均 1 ⁄ α 的指數分佈，以速率 α 轉回 ON。
  • 平均位元率：Rm = R·(1⁄β) ⁄ (1⁄α + 1⁄β) = αR ⁄ (α + β)（ON 時間佔的比例 × R）。
  • On-Off source 通常用 3 個參數描述：R、Rm、1 ⁄ β（平均 burst 長度）。

Poisson、IPP、MMPP（p.40–42）

  • Poisson process（p.40）：速率 λ，到達間隔（interarrival time）是平均 1 ⁄ λ 的指數分佈。
  • IPP（p.41）：和 On-Off 一樣的兩狀態（ON 平均 1 ⁄ β、OFF 平均 1 ⁄ α），但 ON 時不是固定位元率，而是速率 λ 的 Poisson。
  • MMPP（p.42）：例子是 3 狀態 MMPP；在狀態 i 停留平均 1 ⁄ αi 的指數時間，期間是速率 λi 的 Poisson，離開時依 pij 轉到狀態 j。IPP 是 MMPP 的特例（兩狀態，其中一個 λ = 0）。

13. 公式拆解與範例計算

本章公式都以「一個封包（訊框）傳輸時間」為時間單位。G、S 的單位是「個 ⁄ 封包時間」；換成實際數字時，先算一個封包要送多久。

① Poisson 機率

Pr[k] = Gke−G ⁄ k!

符號：G＝每個封包時間平均產生幾個封包；k＝實際產生的個數。

  1. 講義 p.11 的 λ = 4：Pr[0] = e−4 = 0.0183。
  2. Pr[4] = 44 × e−4 ⁄ 4! = 256 × 0.0183 ⁄ 24 = 0.195，和 p.11 圖上紫色峰值（約 0.20）一致。
  3. Pr[3] = 64 × 0.0183 ⁄ 6 = 0.195，和 Pr[4] 一樣高，所以圖上 k = 3、4 兩點並排。

② Pure ALOHA 最大吞吐量

S = Ge−2G　　dS ⁄ dG = (1 − 2G)e−2G
  1. 令 dS ⁄ dG = 0：e−2G 永遠 > 0，所以 1 − 2G = 0 → G = 0.5。
  2. S = 0.5 × e−1 = 0.5 × 0.3679 = 0.184。
  3. G = 1 時：S = e−2 = 0.135，負載加倍，吞吐量反而下降。

意義：通道最多只有 18.4% 的時間在成功傳送，其餘是碰撞或閒置。

③ Slotted ALOHA 最大吞吐量與 slot 的三種結果

S = Ge−G　　dS ⁄ dG = (1 − G)e−G
  1. 1 − G = 0 → G = 1；S = 1 × e−1 = 0.368。
  2. 補充G = 1 時每個 slot 的結果：空的 Pr[0] = e−1 = 36.8%；成功 Pr[1] = 1 × e−1 = 36.8%；碰撞 1 − 0.368 − 0.368 = 26.4%。

④ 換算成實際數字

  1. 通道 1 Mbps、封包 1000 bits：一個封包時間 = 1000 ÷ 106 = 1 ms，通道最多每秒 1000 個封包。
  2. Pure ALOHA 最多 1000 × 0.184 = 184 個／秒（約 184 kbps）。
  3. Slotted ALOHA 最多 1000 × 0.368 = 368 個／秒。
  4. 如果所有站台合起來每秒產生 500 個封包（含重送），G = 500 × 1 ms = 0.5：Pure ALOHA S = 0.5 × e−1 = 0.184 → 184 個成功；Slotted S = 0.5 × e−0.5 = 0.5 × 0.6065 = 0.303 → 303 個成功。

⑤ 補充平均要送幾次才成功

G ⁄ S = 1 ⁄ P0：Pure ALOHA = e2G，Slotted = eG
  1. Pure ALOHA 在 G = 0.5：e1 = 2.72 次。
  2. Slotted 在 G = 1：e1 = 2.72 次；G = 2 時 e2 = 7.39 次，負載越高重送越多。

⑥ 指數分佈

P(W > t) = e−λt　　E(W) = 1 ⁄ λ　　Var(W) = 1 ⁄ λ2
  1. 平均每 ms 到 2 個封包（λ = 2 ⁄ ms）：平均間隔 E(W) = 1 ⁄ 2 = 0.5 ms；Var = 1 ⁄ 4 = 0.25 ms2，標準差 0.5 ms。
  2. 超過 1 ms 都沒有封包：P(W > 1) = e−2 = 0.135。
  3. 0.5 ms 內就有封包：P(W ≤ 0.5) = 1 − e−1 = 0.632。

⑦ On-Off 平均位元率

Rm = αR ⁄ (α + β)
  1. 語音 R = 64 kbps，平均講話 1⁄β = 0.4 s（β = 2.5），平均安靜 1⁄α = 0.6 s（α = 1.667）。
  2. Rm = 1.667 × 64 ⁄ (1.667 + 2.5) = 106.7 ⁄ 4.167 = 25.6 kbps。
  3. 驗算：ON 比例 = 0.4 ⁄ (0.4 + 0.6) = 40%，64 × 0.4 = 25.6 ✓。

⑧ 補充CSMA 的吞吐量

Nonpersistent：S = Ge−aG ⁄ (G(1 + 2a) + e−aG)　　1-persistent（a = 0）：S = G(1 + G)e−G ⁄ (G + e−G)
  1. Nonpersistent，a = 0.01、G = 1：e−0.01 = 0.990；S = 0.990 ⁄ (1.02 + 0.990) = 0.493。
  2. a = 0 時 Nonpersistent 化簡成 S = G ⁄ (1 + G)，G → ∞ 時逼近 1。
  3. 1-persistent，a = 0、G = 1：S = 1 × 2 × 0.368 ⁄ (1 + 0.368) = 0.736 ⁄ 1.368 = 0.538，約是它的最大值。

15. 考前自我檢查

  • 畫出多重存取協定的三大類與各自的例子
    Random access：ALOHA、CSMA、CSMA/CD、CSMA/CA；Controlled-access：Reservation、Polling、Token passing；Channelization：FDMA、TDMA、CDMA。
  • 說明 ALOHA 的基本想法，以及為什麼等待時間一定要隨機
    有資料就送；碰撞後等隨機時間重送。如果等待時間固定，同一批碰撞的封包會在同一時間重送而再次碰撞。
  • 為什麼 ALOHA 的封包長度都一樣？
    封包大小一致時 ALOHA 的吞吐量最大（p.5）。
  • 寫出 ALOHA 流程圖（p.6），Kmax 是多少
    K = 0 → 送 → 等 time-out（2 × Tp）→ 收到 ACK 成功；否則 K + 1，K > Kmax（通常 15）放棄，否則 R ∈ [0, 2K − 1]，等 TB = R × Tp 或 R × Tfr 後重送。
  • 定義 Throughput S 與 Offered load G，說明兩者大小關係
    S：每個封包時間成功送出的封包數；G：每個封包時間嘗試的封包數（新 + 重送）。G ≥ S；低負載 G ≈ S；高負載 G > S；S = GP0。
  • 寫出 Poisson 過程的三個特性與 P(k, T)
    (1) 短區間 Δt 發生一次的機率 λΔt；(2) 兩次以上可忽略；(3) 不重疊區間獨立。P(k, T) = (λT)ke−λT ⁄ k!，由二項分佈令 N → ∞ 得到。
  • 說明 Vulnerable period 為什麼是 2t
    在灰色封包開始前 t 內開始的封包撞到它的開頭，在它傳送期間 t 內開始的撞到結尾，共 2t。
  • 推導 Pure ALOHA 的最大吞吐量
    P0 = e−2G，S = Ge−2G，dS/dG = (1 − 2G)e−2G = 0 → G = 0.5，S = 1/(2e) = 0.184（18.4%）。
  • 推導 Slotted ALOHA 的吞吐量與最大值
    易受干擾期減半成 t，P0 = e−G，S = Ge−G；G = 1 時最大 1/e = 0.368。
  • 比較 1-persistent、Nonpersistent、p-persistent CSMA
    1-persistent：忙就一直聽，閒了以機率 1 送（碰撞多）；Nonpersistent：忙就隨機等再聽（碰撞少、延遲大）；p-persistent：閒了以機率 p 送，否則等一個 slot（介於兩者）。
  • 依 p.24 排出各協定的吞吐量高低
    Aloha < Slotted Aloha < 1-persistent < 0.5-persistent < 0.1-persistent < Nonpersistent ≈ 0.01-persistent CSMA。
  • CSMA/CD 比 CSMA 改進了什麼？有哪三種狀態？
    偵測到碰撞立刻停止傳送（並送 jamming signal）；狀態：contention、transmission、idle。碰撞時能量位準較高。
  • 寫出 CSMA/CA 的時序與流程
    持續感測 → 閒置 → 等 IFS → 仍閒置 → 選 R ∈ [0, 2K − 1]，等 R 個 slot（忙碌就凍結）→ 送 → 等 time-out → ACK 成功；否則 K + 1，K > 15 放棄。
  • 列出五種流量模型與例子
    CBR：傳統語音；On-Off：封包語音；Poisson：傳統資料；IPP：突發資料；MMPP：多媒體。
  • 由 Poisson 推導指數分佈的 CDF、PDF、平均、變異數
    P(W > t) = e−λt；F = 1 − e−λt；f = λe−λt；E = 1/λ；Var = 1/λ2。
  • 寫出 On-Off source 的平均位元率與描述參數
    Rm = R(1/β) ⁄ (1/α + 1/β) = αR ⁄ (α + β)；參數 R、Rm、1/β（平均 burst 長度）。
  • 比較 On-Off、IPP、MMPP
    On-Off：ON 時固定位元率 R；IPP：ON 時速率 λ 的 Poisson；MMPP：多狀態，狀態 i 是 λi 的 Poisson，依 pij 轉移。
