💡 觀念：IEEE 802 只定義到第 2 層，而且把鏈結層再切成兩個子層：上面共用的 LLC（802.2），下面依技術不同的 MAC（802.3、802.11…）。所以不管底下是有線還是無線，上層看到的都是同一個 LLC 介面。

2. LAN 定義與範圍

  • LAN：讓多個獨立裝置（independent devices）在中等地理範圍（moderately sized geographic area）內，透過實體通道（physical communications channel）以中等速率（moderate data rates）直接互相通訊的資料通訊系統（data communication system）。
  • 範圍：PAN（個人，802.15）→ LAN（區域，802.3 / 802.11）→ MAN（都會，802.16、802.6）→ WAN（廣域）；補充802.22 WRAN 為區域型無線網路（Regional Area）。

海底電纜：

  • 跨洲的資料流量約 99% 走海纜，衛星只占很小一部分，因為海纜頻寬大得多、延遲也低。
  • 構造：中心是幾對光纖，外面包鋼絲、銅管（負責供電）和絕緣層。深海段只有水管粗細；靠近岸邊的段落會加上重鎧裝，防船錨和拖網。
  • 中繼器：每隔約 50–100 km 一個，用來放大光訊號，電力由兩端的登陸站從岸上經銅管供應。
  • 容量：一條新纜用 DWDM（密集分波多工，同一根光纖跑很多波長）可達數十到數百 Tbps。
  • 台灣的例子：主要登陸站在宜蘭頭城、屏東枋山、新北八里與淡水等地。連外的國際海纜有 APG（亞太直達）、SJC2、TPE（跨太平洋快速）等；本島連金門、馬祖也靠海纜，2023 年台馬海纜被扯斷造成馬祖斷網，是很有名的案例。
  • 主要風險：船錨和漁船拖網造成的損壞最多，其次是地震（2006 年恆春地震一次弄斷多條海纜，亞洲網路大亂），近年也有疑似人為破壞的事件。
💡 WAN 不在 IEEE 802 的範圍內，那是電信業者與 ITU-T、IETF 的領域，例如 SONET/SDH、MPLS、3GPP 的 4G/5G。

3. LAN 的基本需求（Basic Requirements of a LAN）

規格：資料速率（data rate） 1–1000 Mbps；距離（geographic distances）最多 1–5 km；支援數百台獨立裝置（several hundred independent devices）。講義列出 7 項需求：

  1. 不依賴集中式元件或控制（Minimal dependence on any centralized components or control），避免單點故障
  2. 有效利用共享資源，包括網路通道（Efficient use of shared resources, including the network channel）
  3. 高負載下仍穩定（Stability under high load）
  4. 各裝置公平存取（頻寬、延遲）（Fair access (bandwidth, delay) to the network by all devices）
  5. 可靠、錯誤特性良好（Reliability and good error characteristics）
  6. 易於安裝、重新設定與維護（Easy installation, reconfiguration and maintenance）
  7. 低成本（Low cost）

4. LAN 組成（LAN Components）

  • 電腦／網路裝置（Computers / Networking devices）；講義圖中稱工作站
  • 傳輸系統（Transmission System）：網卡（Network Cards）、線材（Cabling）、空氣（Air）。講義圖中的傳輸媒介：同軸電纜、雙絞線、光纖、radio
    • 補充導向媒介（guided media）：有線，訊號被限制在線材裡傳，例如雙絞線、同軸電纜、光纖。
    • 補充自由介質／非導向媒介（unguided media）：無線，訊號以電磁波在自由空間中傳播。電磁波不需要介質，真空中也能傳（衛星、太空通訊就是這樣），講義寫「空氣」只是日常說法；空氣、牆壁、雨反而會造成衰減。例如無線電、微波、紅外線（最早的 802.11 就定義過紅外線 PHY）。特性：
      • 天生是廣播、共享的：範圍內所有站台都收得到，所以需要 MAC 協調誰能傳，也需要加密（802.11i／WPA2）來防竊聽。
      • 訊號品質不穩：有路徑衰減、多路徑衰落（multipath fading）、障礙物遮蔽，還會受其他裝置干擾，錯誤率比有線高很多，因此 802.11 每個 frame 都要 ACK。
      • 邊傳邊聽做不到：自己發射的訊號遠強於收到的訊號，無法像乙太網路那樣偵測碰撞（CD），加上有隱藏節點問題，所以 802.11 改用避免碰撞的 CSMA/CA。
      • 頻譜受法規管制：Wi-Fi、藍牙、Zigbee 用的是免執照的 ISM 頻段（2.4GHz）和 5GHz、6GHz 免執照頻段，但要遵守發射功率等規定；行動網路、11af 的電視頻段則屬於需執照頻段。
      • 優點：不用佈線，站台可以移動，網路容易擴充，這正是無線 LAN 拓樸會是 Random 的原因。
  • LAN 延伸（LAN Extension）：用訊號增益器（repeater）把多個網路區段（segment）接起來；補充repeater 工作在實體層，只放大轉送訊號，所以接起來的區段仍是同一個碰撞網域。

6. OSI 七層（Open System Interconnection Model - Seven Layers）

層職責重點功能
7 應用層
Application Layer		提供服務給應用程式或使用者（Provides services to application processes or users）FTP、Telnet（Remote Login）、交易伺服器（Transaction Server）、網管（Network Management）、WWW／VoD Server

4 傳輸層
Transport Layer		兩端使用者間達到約定品質的資料傳輸（data transfer between two end users at an agreed on level of quality）建立／維護／終止傳輸連線（Establishing/Maintaining/Terminating transport layer connection）
3 網路層
Network Layer		節點間路由（routing data from one network node to another）路徑選擇（routing path selection）；建立／維護／終止網路連線（Establishing/Maintaining/Terminating network connection）
2 鏈結層
Data Link Layer		節點到節點的可靠傳輸（reliable data transmission from one node to another）無錯誤的訊框傳送（error-free transmission of frames）；IEEE 802 分為 LLC + MAC
1 實體層
Physical Layer		在特定媒介上傳送位元串（transmission of bit streams across a particular physical transmission medium）不支援重傳（Retransmission is not supported）；編碼／解碼（Encoding/Decoding）、擾亂／解擾亂（Scrambling/Descrambling）

分層協定（Layering Protocols）：系統 A 與系統 B 的同一層之間有「對等協定」；實際資料則是一路往下送到傳輸媒介，再在對方一路往上。下面的動畫同時呈現這兩件事。

7. 協定的基本功能（Basic Functions of Protocols）

封裝與解封裝 動畫
虛線是同層之間的對等協定（邏輯上的溝通）；實際資料沿著橘色路徑走：A 往下逐層加 header，經過傳輸媒介，B 往上逐層拆掉。
  • 封裝／解封裝（Encapsulation/Decapsulation）：往下送時每層加上自己的 header（AH、PH、SH、TH、NH），鏈結層還會加上 flag、位址、控制與 FCS；往上送時逐層拆掉。
  • 分段／重組（Segmentation/Reassembly）、連線建立（Connection Establishing）、流量控制（Flow Control）、錯誤控制（Error Control）、多工／解多工（Multiplexing/Demultiplexing）。
  • SDU vs PDU：上一層交下來的資料是本層的 SDU；本層加上 header（控制資訊）後成為本層的 PDU，再交給下一層當作它的 SDU。

💡 解多工靠的是每層 header 裡的「上層是誰」欄位：Ethernet 的 EtherType 指出上面是 IP，IP 的 Protocol 指出上面是 TCP 或 UDP，TCP／UDP 的 port 再指出是哪個應用程式（例如 443 = HTTPS）。接收端就是照這條線一層層往上交。

例子：瀏覽網頁時，一個 Ethernet 訊框最多帶 1500 bytes 的 IP packet（即 MTU）。扣掉 IP 20 B 和 TCP 20 B，每個訊框最多裝 1460 B 的應用資料（即 TCP 的 MSS）；鏈結層再加 18 B（MAC header 14 ＋ FCS 4），實體層另外有 8 B 的 preamble／SFD。

🔁 之後 802.11 會出現同樣的觀念：LLC 交給 MAC 的是 MSDU，MAC 加 header 後是 MPDU；MPDU 交給 PHY 時稱 PSDU，PHY 加上 preamble／header 後是 PPDU。

8. IEEE 802 標準家族

802.1 高層介面（跨各種 802 網路的共通功能）

  • 802.1D Local Bridge：Spanning Tree Algorithm（補充在橋接網路中關閉多餘路徑以避免迴圈）
  • 802.1G Remote Bridge：透過遠端線路連接兩個 LAN
  • 802.1P Traffic Class Expediting 與 Dynamic Multicast Filtering：流量優先權（補充3 bits、8 個等級，放在 802.1Q 標籤內）
  • 802.1Q Virtual LANs（補充在乙太網路訊框插入 4 bytes 標籤，其中 VLAN ID 12 bits）
  • 802.1X Port-Based Network Access Control：以連接埠為單位的認證（補充三個角色：supplicant 用戶端、authenticator 交換器／AP、authentication server 通常是 RADIUS；使用 EAP）

802.2 LLC（Logical Link Control）

  • 所有 802 網路共用的鏈結層上半部；講義重點：可靠度透過 sequence number 與 ACK 達成。

802.3–802.14 有線 LAN／MAN 與諮詢小組

  • 802.3 CSMA/CD（Ethernet）→ 詳見第 1 章
  • 802.4 Token-Bus；802.5 Token-Ring；802.6 DQDB（Distributed Queue Dual Bus，都會網路）
  • 802.7 寬頻技術諮詢小組；802.8 光纖技術諮詢小組；802.9 整合語音與資料 LAN；802.10 LAN/MAN 安全互通
  • 802.12 Demand-Priority（100VG-AnyLAN）；802.14 Cable TV 寬頻網路

11. 考前自我檢查

  • 能說出 IEEE 802 對應 OSI 哪兩層，以及 LLC / MAC 的分工
    對應第 1 層（實體層）與第 2 層（鏈結層）。鏈結層切成上半部共用的 LLC（802.2）與下半部依技術不同的 MAC（802.3、802.11…）。
  • 看到一種拓樸，能說出對應的 802 標準
    Bus → 802.3、802.4；Dual Bus → 802.6；Ring → 802.5；Dual Ring → FDDI；Star → 802.12、802.16；Snowflake → 802.15.1、802.15.4；Mesh → 802.15.x；Random → 802.11。
  • 能說明 SDU 與 PDU 的差別
    上一層交下來的資料是本層的 SDU；本層加上 header 後是本層的 PDU，它又成為下一層的 SDU。
  • 能說出各層 PDU 的名稱，以及解多工靠哪些欄位
    應用層 data／message → 傳輸層 segment（TCP）／datagram（UDP）→ 網路層 packet → 鏈結層 frame（唯一有 trailer FCS 的層）→ 實體層 bits。解多工：EtherType → IP Protocol 欄位 → TCP／UDP port。
  • 能說出 802.1D / 1Q / 1X 各在做什麼
    1D：Local Bridge、Spanning Tree；1Q：VLAN；1X：Port-Based 存取控制（認證）。
  • 能分辨 11a / b / g / n / ac / ax / be 的頻段與速率等級
    a：5GHz OFDM 54M；b：2.4GHz DSSS/CCK 11M；g：2.4GHz 54M；n：2.4/5GHz MIMO 600M；ac：5GHz VHT 6.93G；ax：2.4/5/6GHz HE 9.6G；be：2.4/5/6GHz EHT。
  • 能區分 11ah 與 11af（都在 1GHz 以下）
    11ah：Wi-Fi HaLow，免執照 900MHz，100 kbps、約 1 km，給 IoT 用。11af：White-Fi／Super Wi-Fi，利用 54–790MHz 的 TV white space（需執照頻段），靠認知無線電找空閒頻道；6、7MHz 通道 26.7 Mbps，8MHz 通道 35.6 Mbps。
  • 能說出 11e、11i、11n 在講義中對應的別名或提案
    11e = WME（Wi-Fi Alliance 認證名稱 WMM）；11i 對照 WPA（PSK）／WPA2.0；11n 有兩個競爭提案陣營：WWiSE 與 TGnSync。
  • 能分辨 802.15.1 / 15.4 / 15.6 / 15.7
    15.1 Bluetooth；15.4 Low Rate WPAN（Zigbee 底層）；15.6 Body Area Network；15.7 可見光通訊。
